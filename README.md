# car-assistant

Manager repo for the Car Assistant product. The code lives in two submodules:

| Path       | Repo                                                       |
|------------|------------------------------------------------------------|
| `backend/` | [car-assistant-back](https://github.com/tavangar79/car-assistant-back) — Express · TypeScript · Prisma · MongoDB |
| `client/`  | [car-assistant-flutter](https://github.com/tavangar79/car-assistant-flutter) — Flutter · DDD · Riverpod |

```bash
git clone --recurse-submodules https://github.com/tavangar79/car-asistant.git
```

See `CLAUDE.md` for the CTO workflow, and each submodule's `CLAUDE.md` for project details.
